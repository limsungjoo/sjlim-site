OSS 모델은 JSON 을 코드펜스로 감싸서 준다

Claude 기준으로 짠 파서가 self-host 모델에서 그대로 깨진다. 아직 어느 모델이 어떤 형태로 어긋나는지 다 정리 못 함.

Written
2026.08.09
Tags
#LLM#self-host#파싱

아직 정리 안 됨. 그때의 기록 그대로

Anthropic 모델 기준으로 짠 구조화 출력 파서를 self-host 모델로 옮겼더니 바로 깨졌다.

지금까지 본 형태.

  • ```json 코드펜스로 감싸서 반환
  • JSON 앞뒤에 설명 문장을 붙임
  • 마지막 요소 뒤에 쉼표를 남김
  • 툴 호출 형식이 모델마다 다름

임시로 펜스를 벗기고 가장 바깥 {} 를 잘라내는 전처리를 붙여뒀다. 근본 대응은 아니다.

아직 확인 못 한 것.

  • few-shot 을 붙이면 형태가 안정되는지, 모델별로 다른지
  • 스키마 강제 디코딩을 쓰면 전처리를 지울 수 있는지
  • 어느 실패가 모델 문제고 어느 실패가 서빙 설정 문제인지

정리되면 verified 로 올린다.
